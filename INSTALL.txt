Godot 4 hero preview patch

1. Stop the running game.
2. Unpack this archive into your project folder beside project.godot, preserving folders.
3. Overwrite scenes/hero_visual_preview.tscn when asked.
4. Open scenes/hero_visual_preview.tscn in Godot and press F6 (Run Current Scene).
5. Move with A/D or arrows, jump with Space.

This is an initial playable character prototype, based on the user-provided reference collage. It has one static idle image with a subtle breathing effect; full animation, rigging, combat and final art remain to be done.
