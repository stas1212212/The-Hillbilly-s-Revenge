# Еліан — спокойная стойка (Idle, 12 кадров)

Состояние `idle` теперь поддерживает новый атлас `assets/characters/hero/idle/elian_idle_12.png`. Он **не заменяет** старые анимации движения и атак: если файл отсутствует, контроллер автоматически использует прежние изображения без ошибки.

- Атлас: 3072 × 384 px, 12 кадров по 256 × 384 px.
- Воспроизведение: 8 FPS, циклическое (1,5 секунды).
- Изображение персонажа закреплено по стопам, чтобы во время дыхания/ветра ноги не прыгали.
- `scripts/actors/hero_controller.gd` загружает PNG при старте через `_load_refined_idle_frames()`.
- Масштаб стоящего героя: 0.52; смещение спрайта Y = -42. Эти значения подходят текущему `CollisionShape2D`.
- Дополнительные изображения ходьбы, бега и прыжка остаются временными; финальную анимацию сделаем поэтапно.

## Установка PNG

Двоичный PNG поставляется отдельным ZIP-патчем в чате. Распаковать ZIP рядом с `project.godot` (структуру папок сохранить). После добавления PNG в проект Godot импортирует его автоматически.

Чтобы включить графику в историю GitHub, **после распаковки** выполнить:

```powershell
git add assets/characters/hero/idle/
git commit -m "Add 12-frame Elian idle sprite animation"
git push origin foundation/godot-2d-combat
```

Тест: открыть `scenes/field_prologue.tscn` и нажать F6, ничего не нажимать 2-3 секунды. Если получился статичный спрайт, проверить наличие `res://assets/characters/hero/idle/elian_idle_12.png` и сообщения ошибок Godot.

Исходные иллюстрации созданы как концептуальный 12-кадровый лист. Это тестовая анимация из нарезки и очистки иллюстрации, а не финальная покадровая ручная анимация. Требуется редакторская доводка силуэтов и отдельных кадров.
