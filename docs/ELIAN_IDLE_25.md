# Еліан — Idle: 25 кадров (тестовый этап)

Атлас: `assets/characters/hero/idle/elian_idle_25.png`; размер **1280 × 1920** (5 × 5 кадров по 256 × 384). Контроллер `scripts/actors/hero_controller.gd` автоматически выбирает **эту** анимацию поверх старых idle-12 и idle-60, если файл присутствует.

**Частота:** 12.5 FPS, цикл 2 секунды. Это частота кадров анимации, не частота рендеринга Godot.

Источник: ранее нарисованный пользователем/ассистентом лист из 25 поз. 25 отдельных PNG и атлас подготовлены автоматически, стопы кадров выровнены, часть цветного фона и красных артефактов удалена. Это **не новые 25 вручную доработанных рисунков**, и исходные дефекты контуров/плаща могут оставаться. Проверять качество и петлю непосредственно в Godot.

## Установка

1. `git pull origin foundation/godot-2d-combat` в клонированном репозитории, предварительно сохранив свои несохранённые локальные изменения.
2. Распаковать ZIP-патч из чата непосредственно рядом с `project.godot`, не извлекая каждый кадр вручную.
3. В Godot дождаться импорта, открыть `scenes/field_prologue.tscn`, нажать F6 и проверить стойку и переход в ходьбу.
4. Если подходит, добавить **только арт** в GitHub:

```powershell
git add assets/characters/hero/idle/elian_idle_25.png assets/characters/hero/idle/frames_25/
git commit -m "Add 25 cleaned idle frames for Elian"
git push origin foundation/godot-2d-combat
```

**Пояснение:** текстовый код загрузчика уже закоммичен через GitHub; бинарные PNG передаются отдельным ZIP-патчем, пока их не отправили из локального Git. При отсутствии PNG старые варианты idle работают без ошибки.
