# Еліан — анимация спокойной стойки (60 кадров)

Новый **необязательный** PNG-атлас: `res://assets/characters/hero/idle/elian_idle_60.png`.

- Разметка: **10 столбцов × 6 строк**.
- Кадр: **256 × 384 пикселя**. Размер атласа **2560 × 2304 пикселя**.
- 60 кадров при **30 FPS** = 2 секунды на цикл.
- PNG имеет прозрачный фон. Подошвы выровнены по нижней линии.
- `scripts/actors/hero_controller.gd` автоматически импортирует атлас в `AnimatedSprite2D` при старте. Устанавливается `CanvasItem.TEXTURE_FILTER_LINEAR`.
- Если атлас ещё не скопирован, старая стойка на 12 кадрах продолжает работать. Ходьба, бег и бой не изменяются.
- Масштаб/расположение idle, уже настроенные в контроллере, сохраняются.

## Ограничение исходника

На изображении, которое названо «60 кадров», **фактически 54 нарисованные позы** (9 × 6). Для игрового атласа получены 60 кадров путём включения **шести повторных кадров-удержаний** между исходными позами. Это не 60 уникальных вручную прорисованных кадров. По-настоящему повысить чёткость и добавить детализацию без новой прорисовки исходников невозможно.

## Установка графики

PNG распространяется как ZIP-патч в текущем чате, **не включён в GitHub до выполнения загрузки со стороны владельца репозитория**.

1. Выполнить `git pull origin foundation/godot-2d-combat` в клонированной папке проекта.
2. Распаковать ZIP туда же, где расположен `project.godot`.
3. Открыть Godot, дождаться импорта PNG. Запустить `scenes/field_prologue.tscn` (F6).
4. После проверки отправить **только графику**:

```powershell
git add assets/characters/hero/idle/elian_idle_60.png
git commit -m "Add 60-frame Elian idle atlas"
git push origin foundation/godot-2d-combat
```

Если Godot не видит новый атлас, проверь путь, наличие PNG и ошибки импорта в Output/Debugger. Движок Godot в рабочем окружении автора патча не запускался; сцена требует локальной проверки.
